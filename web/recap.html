          Connect a browser

          This app syncs with Memoir in any browser that runs Chrome extensions: Chrome, Edge, Brave, Opera, Vivaldi, Arc and more.

          1. Add Memoir to that browser from the Chrome Web Store.
          2. Open it there, then Settings and Your data.
          3. Press Link next to Memoir for Windows and choose how to start.
          4. Allow it when the browser asks. Both say In sync.

          Do the same in every browser you use. Everything stays on this computer.
